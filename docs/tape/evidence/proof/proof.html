Tape Proof Check

Checks, in this browser and without sending anything anywhere, that an order book at one moment is on the Verifiable Tape's signed record. It recomputes the book's hash from the levels below, climbs the Merkle proof to the tree root, and verifies the voters' Ed25519 signatures on that root. The only thing it trusts is the voters' published key fingerprints.
